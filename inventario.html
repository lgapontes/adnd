Inventário de AD&D 2ed

Versão 0.0.1


Este é um gerenciador de inventário de itens de personagens para Advanced Dungeons and Dragons 2ª edição. Crie suas campanhas, configure os jogadores e organize o inventário para facilitar o consumo e manutenção dos itens durante os jogos. Ao criar sua campanha SALVE os links indicados, principalmente o Link do Narrador - somente através dele você poderá modificar os dados de sua campanha. Caso o perca não será possível acessá-la como narrador. O Link dos Jogadores pode ser distribuído aos jogadores. O Link de Visualização é acessível por todos neste site e é útil para acompanhar as alterações dos inventários (como por exemplo em uma Stream).
